One image summing up the world's news of Saturday 21 November 2026, drawn as a
newspaper front page: Mexico captures cartel boss "El Chapo Isidro", a Russian
missile hits Zelenskyy's hometown of Kryvyi Rih, COP31 climate talks run into
overtime in Antalya, an AI stock sell-off sinks world markets, the World Court
rules Myanmar committed genocide against the Rohingya — plus the day's briefs.

## How it works

`main.py` (Python 3.13, standard library only) copies `entry.png` to the
output directory. The image is 1024×1024 PNG, drawn with Pillow from verified
AP / Reuters / NYT reporting of the day. Run it twice and both runs write the
same bytes.
